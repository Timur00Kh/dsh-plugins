# Плагины DSH

Здесь будут исходники моих плагинов для DeepSeek Harness.

Каждый плагин размещается в отдельном каталоге `plugins/<plugin-name>/` и получает собственные:

- README с назначением, разрешениями, установкой и удалением;
- manifest/package.json с корректными требованиями совместимости;
- исходники и тесты;
- лицензию перед публикацией или распространением пакета.

Наличие папки в этом репозитории само по себе не делает плагин устанавливаемым через npm или менеджер DSH. Инструкция установки будет у каждого опубликованного плагина.
