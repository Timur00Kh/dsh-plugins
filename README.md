# dsh-plugins

Мои skills и плагины для **DeepSeek Harness (DSH)**.

Независимый community-проект, не официальный продукт DeepSeek или OpenAI.

## Структура

```text
skills/                     # инструкции для AI-агентов
  dsh-codex-auth/
    SKILL.md
    references/
    scripts/                # login, импорт grant, настройка маршрута, тесты
plugins/                    # исходники плагинов DSH
```

## Skills

| Skill | Назначение |
| --- | --- |
| [dsh-codex-auth](skills/dsh-codex-auth/SKILL.md) | Подключение ChatGPT с доступом к Codex через встроенный `openai-codex` в DSH, без дополнительных DSH-плагинов. |

Skill — это инструкция для агента, а не автоматически запускаемый установщик. Агент проверяет установленную версию, просит необходимые разрешения и выполняет настройку вместе с пользователем.

Включены [вспомогательные скрипты](skills/dsh-codex-auth/scripts/README.md): интерактивный вход через pi-ai, импорт grant и добавление маршрута. Изменения по умолчанию работают в dry-run; запись требует остановленного DSH, создаёт бэкап и не печатает токены. Offline-тесты используют только синтетические данные.

### Установка через `npx skills`

Нужны Node.js и npm (`npx`). Команды ниже заработают после публикации публичного репозитория `Timur00Kh/dsh-plugins`.

Посмотреть доступные skills, не устанавливая их:

```bash
npx skills add Timur00Kh/dsh-plugins --list
```

Установить `dsh-codex-auth` в текущий проект (выполните из каталога нужного проекта):

```bash
npx skills add Timur00Kh/dsh-plugins --skill dsh-codex-auth
```

Или установить на уровне пользователя, чтобы skill был доступен в разных проектах:

```bash
npx skills add Timur00Kh/dsh-plugins --skill dsh-codex-auth --global
```

CLI предложит выбрать поддерживаемого агента и место установки. Убедитесь, что выбранный каталог skills читается вашей версией DSH: успешная установка CLI сама по себе не гарантирует обнаружение skill в DSH. Если подходящего варианта нет, скопируйте каталог `skills/dsh-codex-auth` целиком в поддерживаемый DSH каталог skills (например, `~/.agents/skills/dsh-codex-auth`, если он включён в пути поиска вашей установки).

После установки откройте новую сессию DSH и проверьте, что `dsh-codex-auth` появился в доступных skills. Пример запроса агенту:

> Используй skill dsh-codex-auth: настрой встроенный openai-codex через мою подписку ChatGPT без дополнительных DSH-плагинов. Сначала проверь версии и покажи план, не меняя конфиги.

Установка skill не выполняет OAuth-вход, не устанавливает Python-зависимости скриптов и не изменяет настройки DSH. Подготовка окружения и запуск описаны в [инструкции скриптов](skills/dsh-codex-auth/scripts/README.md).

Проверить установленные skills и обновления:

```bash
npx skills list
npx skills list --global
npx skills check
```

Обновить установленные skills (команда может затронуть не только этот skill):

```bash
npx skills update
```

## Безопасность

- Никогда не добавляйте токены, OAuth-grant, callback URL или личные конфиги в репозиторий.
- Авторизация выполняется пользователем на странице OpenAI; секреты не нужно передавать агенту в чат.
- Конфигурация и способы авторизации зависят от версии DSH и провайдера.
- Наличие ChatGPT Plus не гарантирует доступ к каждой модели; квоты и доступ определяет OpenAI.
- Первоначальная настройка проверена на DSH `0.2.2-rc.1` и pi-ai `1.3.0`. Для других версий нужна проверка.
